# DeptRental 모바일 앱

Flutter로 만든 학과 대여 물품 관리 앱의 인터랙티브 데모입니다. 컨셉아트에 맞춘 로그인, 홈, 물품 목록·검색, 상세·대여 신청, 내 대여 현황·반납 처리, 알림 화면을 둘러볼 수 있습니다.

모든 물품과 대여 내역은 시연용 메모리 데이터입니다. 앱을 종료하면 새로 신청하거나 반납 처리한 내용이 초기화되며, 아직 백엔드나 MariaDB에는 연결되지 않습니다.

설치, 실행, 백엔드 및 DB 연동 계획은 저장소 루트의 [DEVELOPMENT.md](../DEVELOPMENT.md)를 참고하세요.
